AI-Powered Banana Leaf Disease Detection with Continual Learning

Banana diseases threaten agricultural productivity, particularly for smallholder farmers who may lack access to agricultural experts. Early detection is essential to prevent disease spread, reduce crop losses, and support sustainable farming.

Our project introduces an AI-powered mobile application that identifies banana leaf diseases through image classification using MobileNetV3, a lightweight deep learning architecture optimized for mobile deployment. Trained on the BananaLSD dataset, the system aims to provide fast, accessible, and reliable disease predictions, even without an internet connection.

Beyond disease classification, the application provides confidence scores, an educational disease dictionary, and access to botanical experts for uncertain predictions when internet connectivity is available.

A key innovation is its continual learning framework, which enables the model to improve through periodically incorporating newly collected and verified images. Using transfer learning and historical data replay, the system aims to adapt to changing field conditions while minimizing catastrophic forgetting.

By combining efficient computer vision, accessible agricultural support, and adaptive learning, this project aims to democratize plant disease detection and empower farmers with practical, evolving AI technology.
